# AI News Hub — 第二阶段功能扩展设计

## 概述

基于已上线的 AI News Hub 网站，新增 14 项功能，分三期实施。并将网站从"新闻聚合站"转型为**个人仪表盘**（Personal Dashboard）。

## Phase 1 — 纯前端功能

### 1.1 布局改造

**目标**：从三栏新闻布局 → 个人仪表盘布局

**改动文件**：
- `src/pages/index.astro` — 重构布局，新闻缩小，工具区扩大
- 所有新组件新增

**技术方案**：
- Astro 组件静态渲染
- 交互通过客户端 JS（无框架依赖）
- 折叠面板用 `<details>` / `<summary>` 或 JS toggle

### 1.2 发薪倒计时

**组件**：`src/components/SalaryCountdown.astro`
- 发薪日：每月 20 号
- 节假日逻辑：如 20 号遇周末/节假日，提前到最近工作日
- 内置 2025-2026 中国法定节假日表
- 显示：距离发薪 X 天 X 时
- 发薪当天显示："🎉 今天发工资！"
- 节假日提前提示

### 1.3 随机决策

**组件**：`src/components/RandomPicker.astro`
- 预设类别："今天吃什么"、"去哪玩"、"看什么"
- 用户可自定义选项（存 localStorage）
- 点击随机按钮，滚动动画后出结果

### 1.4 电力计算公式

**组件**：`src/components/ElectricalCalc.astro`
- 电缆截面计算：输入电流/电压/距离 → 推荐平方数
- 欧姆定律：U/I/R/P 互算
- 交直流转换
- 功率计算

### 1.5 每日科普加长版

**改动**：`scripts/fetch-knowledge.mjs` → 每天累积 5 条
**组件**：`src/components/DailyKnowledge.astro` → 列表展示，默认 3 条，可展开

### 1.6 每日文摘

**脚本**：`scripts/fetch-digest.mjs`
- 精选 100+ 条世界名著金句（中文版）
- 每日轮换 1 条

**组件**：`src/components/DailyDigest.astro`
- 卡片风格：引号 + 书名 + 作者
- 数据源：`src/data/digest.json`

## Phase 2 — API 集成

### 2.1 邢台天气
- API: wttr.in（免费，无需 key）
- 组件：当前温度 + 24h 小时预报 + 3 天预报

### 2.2 汇率计算
- API: frankfurter.app（免费）
- 组件：金额输入 + 货币对选择 + 实时换算

### 2.3 购物比价面板
- 组件：搜索框 + 淘宝/京东/拼多多/值得买跳转链接

### 2.4 Spotify 音乐播放器
- 嵌入 Spotify iframe（公开歌单）
- 右上角固定，可折叠

### 2.5 A股/港股/美股行情
- 数据源：新浪财经 + Yahoo Finance（延迟数据）
- 组件：主要指数 + 搜索 + 涨跌显示

### 2.6 私人豆瓣封面抓取
- 替代 API：OpenLibrary（书籍）、TMDB（影视）

## Phase 3 — 动态后端功能

### 3.1 私人豆瓣
- Cloudflare D1 + Pages Functions
- 书籍/音乐/电影/剧集 评分+短评 CRUD

### 3.2 值班表
- localStorage 或 Cloudflare D1
- 月视图日历可编辑

### 3.3 中国地图
- Leaflet.js + OpenStreetMap
- 默认中心：邢台

## 实施路线图

| Phase | 功能 | 
|-------|------|
| **Phase 1** | 布局改造 + 发薪倒计时 + 随机决策 + 电力计算 + 科普加长 + 每日文摘 |
| **Phase 2** | 天气 + 汇率 + 比价 + Spotify + 股票 + 封面抓取 |
| **Phase 3** | 私人豆瓣 + 值班表 + 中国地图 |

## 设计原则

- **渐进增强**：分阶段上线
- **优雅降级**：API 失败时友好提示
- **一致性**：UI 与现有组件统一
- **新闻不再突出**：折叠在底部，但保留
